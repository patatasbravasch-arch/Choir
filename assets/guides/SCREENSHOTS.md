# Freesound website screenshots

Captured from the real Freesound website on 27 October 2026:

- `freesound-token-instructions.webp`: the Token authentication section of https://freesound.org/docs/api/authentication.html#token-authentication.
- `freesound-api-application.webp`: the unsubmitted Create new API credentials form at https://freesound.org/apiv2/apply.
- `freesound-api-key-column.webp`: the credentials heading and column headings on that same page. The table contained no credentials when captured; the image does not depict a generated or masked key.

The images were cropped to the relevant content, excluding account navigation,
and encoded as lossless WebP. Decoded pixels were checked against the cropped
PNG originals. The page content was not redrawn or modified. No credentials
were created, submitted, or exposed for these captures. API terms were left
unchecked. The website can change after this capture date.

The build embeds the screenshots in the frontend, so opening the guide makes no
external image requests. Other SVG pictures in this folder are illustrations,
as identified in their captions.
