# Changelog

Release notes for Choir on the `lunch-test` and `staging` branches, newest first. A few lunch-test builds between staging.29 and staging.30 were numbered `1.1.6-lunch-test.N`.

Version **1.1.9-staging.64** renumbers lunch-test above the 1.1.8 release on `main`, so Lumiverse offers it as an update, and records `main` as merged. Timeout messages now name the request that stopped (Planner, Sound effect, Music or Voice search) instead of calling every backend request TTS; no Choir backend request synthesizes speech. Jev planning waits up to 90 seconds instead of 15 before reporting a timeout or using the enabled LLM fallback, because a Lumiverse Decision connection can be backed by a slower model and Jev asks several rounds of questions. The `planJev` backend action repairs duplicate cast names before validating, like the `plan` action, and uses the selected Planner connection for Fish voice fallback. Message Sections menus follow scrolling and resizing only while open, so long chats no longer run one scroll handler per message. The unused `fishaudio`, `classifyJev` and `classifyWithJev` backend actions are removed, along with the duplicate delivery code in the backend bundle. `Install.ps1` copies only the runtime files and checks that `dist/` was built. Replies containing `{{user}}` now plan when no Lumiverse persona is selected: Choir reads it as "User", as Lumiverse displays it, and the placeholder persona row voices those lines, instead of stopping with "Set your persona name". With **Default Decision connection** selected and no default set in Lumiverse, Jev now explains where to choose a connection instead of showing the host's bare error. Long replies start sooner: grouped or not, their first clips are about 300, 700 and 1,400 characters, cut at sentence ends, before the normal limits apply; replies of up to 1,200 characters (900 with SFX) are still sent whole. In testing, first audio arrived after 6.9 s instead of 10.7 s on Gemini and 7.1 s instead of 16.3 s on Fish, with every later clip ready before it was needed. Fish community casting starts every speaker's search at once and then chooses in order, so no two speakers share a voice (24.5 s to 12.3 s for three speakers). The planner reports bad keys, rate limits, unknown models and unsupported parameters after one request instead of retrying the reply in parts, retries a model that accepts only its default temperature without one (and remembers that for the connection), and explains when a model spends its output on reasoning. Test planner now sends the same temperature as planning. In one-connection mode, a voice saved for another connection is used only when that connection offers the same ID, so switching from Gemini to Fish casts Fish voices instead of failing on Gemini names. Play pressed while a connection switch is still loading voices waits for it instead of doing nothing. A lead whose card profile name ends in a full stop is no longer split into two cast rows; saved duplicates merge into one row that keeps the voice. Speech now passes a soft clipper (unchanged below 80% of full scale, smoothly rounded above), so loudness matching may raise a clip until its peaks reach 1.4× full scale instead of 0.95×. On Fish, voices that ended 2–3 dB under the target because of brief peaks now reach it; every voice measured within about 2 dB. Character volumes above 100% no longer hard-clip, and effects, ambience and music bypass the clipper. Sound effects that land on the same break, or less than 12 characters of speech after the previous effect, keep only the first; several unmatched triggers used to stack at the start of a segment and play back to back. Play pressed while a chat is still loading its voices waits for the load, and a Play interrupted by that load starts again instead of being ignored. Fixes from a code review: lines that begin with Part, Act, Book, Scene, Episode, Chapter or Volume are dropped only when they are real headings (a number, Roman numeral or number word), so prose such as "Part of me wanted to stay." is read again. Say name as respells the name as written or in capitals only, so Will and Rose no longer change "he will go" or "the sun rose". A quote mark after a digit (6'2") is an inch mark, and a straight quote no longer runs across a blank line; a speech left open at a paragraph end stays dialogue. Sound effects whose trigger words are not in the text are dropped instead of playing at the start of their segment. With grouping off, the first two passages of a reply open with the startup clip sizes, and later passages are no longer cut for startup. Clear chat audio asks for a second tap before deleting every recording. Fish S2 now receives each delivery direction as one cue, commas kept: "Clear, measured narration" is [Clear, measured narration] instead of [Clear][measured narration], and "warm, slightly amused, not sarcastic" no longer produces a separate [not sarcastic]. Only full stops and semicolons still separate cues. Directions that ask for nothing in particular, such as "Natural, conversational delivery" or the planner's "natural, matching the scene" fallback, send no cue. Release notes moved from the README to this changelog.

Version **1.1.6-staging.58** adds optional **Paranoid mode** in **Settings → Planner**, revealing **Playback → TTS inspector**. Inspect prepared requests before Play, or the exact request bodies used for the last 20 attempted TTS calls: final text, model, voice ID, delivery parameters and per-speaker grouped turns. The inspector shares the real request builder and captures actual bodies at the fetch boundary, independent of whether LLM or Jev planned the reply. It makes no extra provider calls and includes no connection credentials. Request logs stay in memory and clear on reload, chat change, disabling the mode or Clear call log. Cache hits and saved Replay do not invent new calls. These are Choir-to-Lumiverse bodies; the relay can format the downstream provider request further. See [the inspector guide](docs/tts-inspector.md).

Version **1.1.6-staging.57** restores the hidden **Playback → Speech plan** entry and shows the effective delivery direction beneath each spoken block. Emotion and intensity are expressed together (for example, “Slightly amused, conversational”), rather than as a separate numeric intensity setting. The display reflects the current delivery mode, base override, accent and pronunciation, updates when voice settings change, and makes no provider calls. A hint beside each character's Delivery setting points to the plan. Play uses the displayed directions; saved Replay retains its recorded performance.

Version **1.1.6-staging.56** fixes grouped message controls throwing a global error when a saved reply still needs an automatic voice choice. Version **1.1.6-staging.55** asks the LLM to choose emotion and acting intensity together in its existing casting call. Gemini receives the degree in its delivery instructions and Fish S2 receives it in bracket cues. Replan, then Play to apply the new guidance; saved Replay keeps its original recording. Version **1.1.6-staging.47** makes Fish casting practical: a short brief such as **clear, calm narrator** or **playful, confident male** guides the choice.
