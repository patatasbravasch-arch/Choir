# Paranoid mode: inspect TTS requests

1. Enable **Choir → Settings → Planner → Paranoid mode · inspect TTS requests**.
2. Plan the message normally with LLM, Jev or Local.
3. Open **Playback → TTS inspector**, also linked from **Speech plan**.

**Prepared requests** shows the bodies that the current plan and settings prepare, after voice selection, pronunciation changes, tone injection, chunking and grouping. This view makes no planning or TTS calls. Use **Refresh view** after changing playback settings. Prepared requests may reuse cached audio rather than cause a new call.

**Attempted calls** records the actual body used at Choir's TTS fetch boundary. It includes successful, failed, pending and cancelled attempts, newest first. It also labels voice previews separately from speech playback. Existing cached audio and saved Replay do not create a log entry. The option does not pause or require approval before synthesis.

Each read-only JSON field can be selected and copied. Check:

- `text`: the final outgoing text, including any Fish cues or older Gemini prompt wrapper.
- `voice`: the requested voice ID, not its catalogue description.
- `model` and `connectionId`: the exact destination selection.
- `parameters`: delivery instructions, accent settings and other parameters generated by Choir.
- `parameters.turns`: each speaker's name, voice ID, text and style in a grouped request. The top-level voice alone does not describe all speakers in that request.

This is the exact request from **Choir to Lumiverse**. Lumiverse may format it further for Google, Fish or another provider. A correct requested voice ID does not prove that the provider's recording followed every instruction.

The log holds at most 20 attempted calls in memory for the open chat. It clears on reload, chat change, disabling Paranoid mode or **Clear call log**. Only the on/off preference is saved. The inspector serializes selected request fields rather than the connection object, so it does not include API keys, authentication headers or stored connection credentials.
