# Drawer navigation

The four main tabs stay visible while editing. Every settings page returns
directly to its tab; Escape also returns from a settings page.

| Tab | Everyday controls | Direct editors |
| --- | --- | --- |
| Cast | In this reply / All saved, add/edit/remove characters | One character editor with voice, accent, delivery, aliases, pronunciation and speed; Automatic voices |
| Playback | Auto-plan/play, speed, gap, loudness, highlighting, follow narration, soundscape and Freesound key | Customize mixer, Volume limits, Speech plan, Attribution JSON |
| Saved | Replay/download/delete recordings, Download all, audio retention | Complete mixes stay individual WAVs inside the ZIP |
| Settings | A short directory | Connections, Planner, Text filters, Performance, Interface, Cast tools |

Setup guide is always at the top of the drawer. It opens Quick start, Guided or
Custom setup; first installation opens the chooser automatically. Postponing
shows Continue setup. Switching modes preserves the draft; closing discards it.

All existing storage keys are retained. Inactive characters remain saved and
become visible through All saved or when they return to the reply. This layout
adds no planner calls or synthesis calls and no background polling.
